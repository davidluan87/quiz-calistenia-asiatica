# Quiz Calistenia Asiática

Landing page / quiz interativo (single-page HTML) do programa de Calistenia Asiática Atlas.

- `index.html` — página única com o quiz, projeção de resultados e página de oferta (VSL).

## Como visualizar localmente
Abra o `index.html` no navegador, ou rode um servidor estático:

```bash
python3 -m http.server 8000
# acesse http://localhost:8000
```
